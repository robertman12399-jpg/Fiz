# ФизМат RPG — многофайловая версия

Исходный HTML разделён на отдельные JS-модули и CSS. Редактируй файлы в `src`, затем запускай `build.py` или `build.bat`. Готовый автономный файл появится в `dist/Fizika.html`.

## Структура
- `src/index.html` — HTML-шаблон
- `src/css/style.css` — стили
- `src/js/` — логические модули приложения
- `build.py` — сборщик
- `build.bat` — сборка в Windows
- `build.sh` — сборка Linux/macOS
- `dist/Fizika.html` — итоговый самостоятельный HTML
